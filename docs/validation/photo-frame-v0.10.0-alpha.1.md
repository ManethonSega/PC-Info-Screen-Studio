# PC Info Screen Studio 0.10.0-alpha.1 validation

This pull request validates the photo-frame and hybrid display modes already applied to the current app on `main`.

Validation scope:

- Info Screen, Photo Frame, and Hybrid modes
- Multi-photo and folder playlists with drag reordering
- Global and per-photo timing, fit, crop, focal point, captions, and transitions
- Embedded portable photos and linked folders
- Album presets, watched folders, scheduling, resume position, and tray controls
- 480 × 320 preprocessing cache, EXIF orientation, next-photo preload
- Photo Frame and Hybrid renderer smoke paths
