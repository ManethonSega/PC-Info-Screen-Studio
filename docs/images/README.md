# Interface screenshot provenance

The README gallery and secondary control captures are from Windows CI run [38543047505](https://github.com/ManethonSega/PC-Info-Screen-Studio/actions/runs/38543047505), for alpha.13 source commit `2c807cecec5acba62c767512c57a67bd3abddf0f`. The ControllerChecks harness captured the actual WPF controls with illustrative editor content and sample hardware readings. They show the navy/slate/cyan interface, including Hardware Name controls and rendered colour emoji.

These captures establish interface appearance, not physical-display reliability. Historical validation documents retain their original test results even where they link to refreshed gallery images.

`video-playback.png` and `export-diagnostics.png` are actual alpha.14 WPF captures from PR Windows check [38561995969](https://github.com/ManethonSega/PC-Info-Screen-Studio/actions/runs/38561995969), head `c29668bf0c506894a83df6a235068b4096b424f4`. The video image uses the original synthetic colour fixture paused on its first frame. It demonstrates decoding and controls, not physical playback smoothness.
