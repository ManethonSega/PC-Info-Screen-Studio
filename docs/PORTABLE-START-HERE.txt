PC Info Screen Studio, portable alpha

1. Extract this entire folder to a permanent location on your PC.
2. Run PCInfoScreenStudio.exe. No separate .NET installation is needed.
3. Plug in your screen. Choose 3.5-inch or 5.2-inch in the top bar, then
   choose Detect and connect screen or Start display. Close other screen software.
4. Choose Info Screen, Photo Frame or Hybrid in the top-bar Mode selector.
5. Add a widget on the left, then choose its Source on the right. SEARCH filters
   that source list; Clear shows all sources. Searching does not add widgets.
6. Choose Save theme to update your reusable theme file.

Settings is in the top bar. Scroll to RUNTIME for:
- Start with Windows: adds a Windows Startup Apps entry and requests one-time approval
  for a per-user scheduled task. The app starts in the tray when you sign in.
- Start display automatically with the app: reconnects your last successful screen.
- Keep running in the tray when closed: closing the window leaves output running.

If full hardware sensors are unavailable, open Settings > HARDWARE SENSORS.
PawnIO installation is optional and needs explicit confirmation. The verified
prerequisite is bundled in Prerequisites. Administrator sensor access requires an
administrator Windows account. Manual launches may still show Windows UAC.

Double-click the tray icon to show the editor. Choose Exit in its menu to stop.
Exit and Windows logoff save a private resume snapshot. Reopening restores the
last mode, themes, layers, linked photos and working edits. Save theme is still
needed to update a reusable theme. Original photos stay on your PC.

Keep all files in this folder together. Opening the app from a moved folder may
need approval to update its Windows startup task. Automatic updating is not included.

This is an unsigned alpha, not a finished consumer release. Silent video widgets use
Windows codecs; H.264 MP4 is recommended. Serial and 5.2-inch USB output use
different frame-rate limits. At most two videos play; use Full HD or smaller. Device support includes
Revision-A 480 x 320 USB serial displays and experimental TURZX 5.2-inch
1280 x 720 WinUSB output. See DEVICE-COMPATIBILITY.md and
VALIDATION.md for evidence and remaining physical-device checks.

TURZX 5.2-INCH (EXPERIMENTAL)
Close TURZX software and use its smart-screen mode. Choose
5.2-inch / 1280 x 720 in the top bar, then press Start display.
The canvas and loaded themes fit the chosen screen automatically.
Both screens can stay connected; the app follows the chosen screen.
Keep USB protocol on Auto.
If the device is missing or WinUSB access is unavailable, check its hardware
IDs and current Windows driver before changing anything. The app does not
install or replace a display driver. Desktop Mode and SD-card playback are
separate vendor features and are not controlled by this alpha.

VIDEO AND TROUBLESHOOTING
Choose Video under Media in Info Screen or Hybrid overlays. Use Media properties
for Fit, Loop, Speed, FPS, Pause video and Restart video. Sources must be Full HD
or smaller and under 512 MiB. Audio is never played. Physical rates depend on USB
bandwidth. Native 5.2-inch H.264/SD-card playback is not implemented.
Settings > Troubleshooting > Export diagnostics saves a local JSON report.
Attach it yourself to a bug report if needed. No photos, theme content, account
names, personal paths or raw error messages are included; nothing is sent automatically.
