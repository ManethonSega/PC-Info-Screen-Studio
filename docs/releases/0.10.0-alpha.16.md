# PC Info Screen Studio 0.10.0-alpha.16, portable alpha

Adds bounded 4K input downscaling and clearer, recoverable video playback controls.

Sources up to 3840 × 2160 (4K, or portrait equivalent where the Windows codec supports it) are now accepted and downscaled to the selected screen. This removes the previous Full HD restriction that rejected the reported 277 MB file. The 512 MiB import limit remains. H.264 MP4 is recommended; other codecs still depend on installed Windows support. 720p sources use less PC decode work. No native display H.264/SD-card mode is introduced.

The video FPS editor now validates the selected display's actual limit: 3.5-inch serial uses 3 fps Auto / 5 fps maximum, and 5.2-inch WinUSB uses 12 fps Auto / 20 fps maximum. Previous versions silently clamped requests such as 21 or 22 to 20. GIFs keep their own 60 fps ceiling. Selecting Automatic optimization clears a manual FPS value to 0; entering a positive video FPS leaves Auto mode. USB transfer backpressure still applies.

Healthy playback continues when FPS changes. An ended or failed decoder now reopens after an explicit playback-control edit instead of leaving a permanently cached stopped worker. Restart video remains available without deleting/reimporting the widget.

Export diagnostics now includes requested/effective FPS, playback controls, sample and media-clock timestamps, progress counts, frame age and stopped-worker state. The last ten disposed video sessions retain a path-free snapshot so removing a video does not erase all previous playback evidence. No media, names, personal paths or raw messages are exported or uploaded.

Validation uses original generated 720p and 4K fragmented H.264 clips at both output sizes, live FPS changes, Auto, looping, EOF, stopped-worker recovery, Restart and cleanup. Actual WPF FPS/Auto/GIF controls and diagnostic privacy are checked, alongside the full controller/WPF suite and published EXE/extracted ZIP smoke tests. The owner's specific freeze remains unreproduced and its cause is unconfirmed; export diagnostics while frozen before Restart/removal if it recurs. The larger customer's file and codec were not available for exact-file testing.

Exit the previous version from its tray menu, extract the full ZIP into a new folder and run PCInfoScreenStudio.exe. Existing themes remain compatible.
