# PC Info Screen Studio 0.10.0-alpha.28, experimental Phanteks Matrix workspace

Select **Phanteks Matrix 900 · 90 × 10** in the top-bar Screen menu. The editor switches to dedicated Matrix controls with one-panel, three-column and six-tile layouts. Each tile can show text, a supported sensor, a UTC clock or static pixel art. Images can be imported and resized into a tile. Pixel editing supports mouse painting and arrow/Space/Delete keyboard controls.

LCD themes, mode selections and dock arrangements remain separate. Matrix edits save on this PC through validated settings/recovery. Start display connects its HID interface; Apply sends a layout snapshot. Pixel uploads wait for matching acknowledgements. Sensors are blanked when unavailable rather than represented as zero. Brightness updates through the active Matrix connection after Apply.

This is experimental interoperability support derived from static inspection of the owner's NexLinq 1.5.0.1 files. Runtime identity: 2E3C:6500. Firmware newer than V1.0.0.4 is required for the observed telemetry format. The app neither enters bootloader mode nor updates firmware. Close NexLinq before starting output here. Actual panel output still needs owner qualification; a report that settings were sent does not certify the physical result.

Native firmware text is limited to 50 printable ASCII characters. Existing LCD Unicode/emoji rendering is unchanged. Matrix image import is static; GIF uses its first frame. Text previews approximate the firmware font, and the clock uses UTC. Disconnect may leave the controller displaying its last visual.

[Research and protocol evidence](../research/PHANTEKS_MATRIX900.md) records file hashes, packet fields, layout mapping and outstanding physical checks. No vendor program, DLLs, firmware, fonts or artwork are redistributed.
