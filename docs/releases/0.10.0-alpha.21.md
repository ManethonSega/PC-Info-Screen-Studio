# PC Info Screen Studio 0.10.0-alpha.21, UI refinement

Refines the existing native WPF interface while retaining its three-pane editor, direct Add buttons, navy/cyan palette, mode workspaces and top-bar brightness control.

Canvas tools wrap at compact sizes. Quieter toolbar buttons, simpler inspector headings and a cleaner canvas surround reduce visual clutter. Widget kinds have readable names, and layer actions say Duplicate and Delete. Editor inputs, colour actions, screen/mode choices and layer controls expose contextual accessible names. Frequent actions and dropdowns respond immediately, consecutive toolbar tooltips appear sooner, and Settings closes with Escape.

The saved theme format, user artwork, colour emoji, media rendering and display transport are retained. The development package is identified separately from alpha.20; creating this source version does not publish a GitHub release.

See [UI design decisions and verification scope](../UI_DESIGN.md). Windows build, controller/WPF checks and capture review are required before describing this candidate as verified. Interactive DPI, Narrator and high-contrast checks remain separate.
