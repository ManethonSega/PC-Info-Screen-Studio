# Alpha.35: Matrix progress bars, pixel-art bank and rocket flight

**Progress bar** adds a normal selectable layer. Choose one of twelve native
presets: diamond segments, solid heart, potion battery, coin ticks, crystal
diagonal, skull chevrons, lightning energy, hourglass diagonal, shield battery,
solid bomb, arrow segments or heart pips. All support 4-, 5- and 10-dot heights,
an editable span and colour, minimum/maximum range, and either a source from
the full sensor picker or a manual value. Sensor bars share missing-reading,
alarm and Apply behaviour with value widgets.

**Pixel art bank** opens a thumbnail gallery with 21 selected designs from the
supplied EPS sheets. Clicking one adds an independent editable layer. Native
4-/5-/10-dot variants include hearts, star, fire, mushroom, ghost, skull,
lightning, potions, bomb, coin, gems, arrows, cloud, hourglass and rocket. Small
silhouettes and the rocket were fitted directly to the LED grid where ordinary
downscaling lost their features. Changing height selects the corresponding
variant. Painting, clearing or importing makes the layer custom artwork so
later height edits do not replace the user's edits with the bank original.

**Rocket flight** adds an animation layer. Direction reverses both travel and
the sprite so its nose faces forward. Speed is 1–20 dots/second. The width is
the flight area: 90 spans both panels; 60 or 30 can keep it on one. Move the
area with the existing position controls or dragging. **Play animation**
controls playback; edits still require Apply for physical output. Preview
animation runs while the Matrix workspace is visible, including disconnected
preview. The output uses the existing 200 ms bounded update loop and ACK-gated
RGB upload; physical smoothness still requires hardware qualification.

The canvas marks the first **60 dots as the side panel** and the remaining
**30 as the front panel**. Its separator and labels are editor guides and are
never sent to the LEDs.

Original EPS files are development inputs, not runtime dependencies. The
embedded art bank needs neither Ghostscript nor an EPS decoder on Windows.
See [asset adaptation notes](../research/MATRIX_ART.md).
