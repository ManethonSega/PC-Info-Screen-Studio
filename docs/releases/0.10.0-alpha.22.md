# PC Info Screen Studio 0.10.0-alpha.22, docked workspace

The editor's sidebars become slim labelled strips with independent collapsible panels. Keep several sections open, adjust their heights and widths, or move panels up/down with the header actions. Themes, Widgets, Media, Photos and Layers stay on the left; Properties and Sensors stay on the right. The arrangement is remembered between launches. Reset workspace restores the defaults without modifying a theme.

Fit adjusts the full preview when the window, dock widths, screen model or orientation changes. The physical canvas resolution and widget positions remain fixed. Clear Fit for manual 10% to 300% zoom, or select 100%. Manual zoom remains stable when panels resize. Compact windows constrain effective dock widths while preserving saved preferred widths.

Panel toggles, resizing and reordering support keyboard use. Mode-specific tools hide without losing preferences, and Live view hides both docks. Existing top-bar display controls, palette, colour emoji, rendering and theme formats are preserved.

This is the docked foundation. Free dragging and floating windows follow interactive qualification. This candidate does not publish a GitHub release. Build, WPF interaction checks and native capture review are tracked in the matching validation note; interactive DPI, Narrator, high contrast and physical hardware remain separate checks.
