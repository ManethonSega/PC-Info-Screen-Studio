# PC Info Screen Studio 0.10.0-alpha.18, portable alpha

Automatically follows a replacement screen during reconnect when the previously selected display is gone and exactly one recognized display of the other family is attached. Switching between 3.5-inch serial and 5.2-inch USB updates the remembered identity, screen model, canvas and video rate profile before output resumes. With both screens connected, the app keeps your selection. Manual Stop, an explicit choice of an unavailable family and ambiguous/unrelated serial devices are respected. Automatic display startup/reconnect must be enabled; Windows device enumeration and retries can still take time.

The owner's everyday hardware checks are recorded as passed on their setup: overnight tray operation, restart, sleep/wake, unplug/replug, both screens attached and repeated mode changes. The report did not specify the tested build, exact duration or resource traces. The new automatic handoff has separate software checks and awaits a physical retest.

The video help now makes the 3.5-inch limitation clearer. Full-screen raw-pixel output can look like a slow slideshow with visible repainting. Existing partial updates help when only a small area changes; a smaller video widget over a static background can reduce transfer work. This release does not change the serial wire protocol or claim smooth full-screen video. The 5.2-inch WinUSB JPEG path remains separate.

Regression checks exercise handoff in both directions, connection release/resume, saved identity/family and notification order, both screens attached, a live connection, unrelated serial adapters, multiple replacements and explicit absent-family selection. Full Windows/controller/WPF and published EXE/extracted ZIP checks gate release.

Exit the previous version from its tray menu, extract the full ZIP into a new folder and run PCInfoScreenStudio.exe. Keep automatic display startup enabled to use automatic reconnect and handoff.
