# PC Info Screen Studio 0.10.0-alpha.29, Matrix typography and direct selection

In Phanteks Matrix 900 mode, click a column or tile in the preview to select it. Changing tiles does not paint into them. Ctrl+arrow keys select adjacent tiles; Home and End select the first and last. The current tile has a cyan outline and a selection caption. Pixel painting and its arrow/Space/Delete controls remain available.

Text uses the entire 10-pixel height in one-panel and three-column layouts. Word gaps are capped at three LEDs, including repeated spaces. Six-tile layouts default to four dots per row, with the two middle rows empty. Row height can be changed to five dots each, without a gap. Hidden rows of existing artwork are preserved and become visible again with five-dot rows.

A shared pixel renderer now feeds both preview and USB output for text, selected sensors and the UTC clock. The firmware has no exposed exact-height/spacing option. Apply sends the rasterized layout; live updates resend only changed tiles through the acknowledged RGB path. Scrolling refreshes have one operation in flight and no queued frames. Existing sensor blank/resume behavior and brightness controls remain in place. ASCII text stays limited to 50 characters; GIF import remains first-frame only. LCD themes and their rendering are separate.

This is an experimental candidate. The owner's physical Matrix still needs to qualify RGB updates, row geometry and scrolling throughput. Automated tests and successful writes cannot certify the physical panel. Close NexLinq before starting output here.
