# PC Info Screen Studio 0.10.0-alpha.17, portable alpha

Fixes large Info Screen themes failing to open with “Theme assets exceed the 1 GiB safety limit.”

Previous versions could save a theme larger than their loader could open. Removing or replacing video widgets also left their old imports in the asset list, and every import was included in the saved package. Alpha.17 uses one 4 GiB expanded-asset budget for both saving and loading, enforced before writing/extraction. Theme metadata is capped at 16 MiB and stream copies are checked against their declared sizes.

Saved package snapshots omit unused media. Opening an older package skips unused media before extraction and keeps the authored layout. Visible and hidden widgets, Hybrid layers, embedded photos and the imported font palette retain their assets. Live workspace files/metadata remain available for Undo. Opening does not rewrite the original archive. Saving produces a compacted package, with video bytes stored without redundant ZIP deflation.

Package I/O runs on background workers. Writes use a unique pending file and replace the destination only after success; failures/cancellation clean pending files and preserve existing themes. Edits made while a snapshot is saving remain marked unsaved. Video import/playback limits and the display FPS profiles remain unchanged.

Validation generates a legacy package above 1 GiB and checks opening plus save/reopen, retained media/layout, Undo source availability and original-file integrity. Other checks cover orphan media, 4 GiB budget rejection before extraction/write, malformed declared sizes, path checks, cancellation and failure cleanup. Full Windows/controller/WPF and published EXE/extracted ZIP smoke tests gate release. No customer theme or media is published. The actual reported `.t3theme` was not attached for exact-file testing.

Exit the previous version from its tray menu, extract the full ZIP into a new folder and run PCInfoScreenStudio.exe. Open the existing `.t3theme`, then use Theme actions > Save as to create a cleaned copy while keeping the original.
