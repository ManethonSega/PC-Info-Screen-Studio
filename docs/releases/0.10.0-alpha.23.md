# PC Info Screen Studio 0.10.0-alpha.23, separate photo and Hybrid tools

Photos now contains only photo import, the playlist and playback/removal controls. Slideshow, Captions, Sources and Hybrid Overlays have their own labelled dock entries. Open, collapse, stack and reorder each independently. Existing Photos/Layers arrangements are retained; the new panels start collapsed.

Photo Frame shares the same photo/slideshow/caption/source organization. Overlays appears in Hybrid only. Mode-specific settings and playlists, saved theme formats, canvas fitting and device output behavior are preserved.

Windows verification and native capture review for the latest revision are recorded in [draft PR #32](https://github.com/ManethonSega/PC-Info-Screen-Studio/pull/32). This is a development build, not a published release.
