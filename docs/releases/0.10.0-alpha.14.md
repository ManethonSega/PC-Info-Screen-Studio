# PC Info Screen Studio 0.10.0-alpha.14, portable alpha

Silent video widgets and a local diagnostics export are now available.

## Video

Choose Video under Media in Info Screen or Hybrid overlays. H.264 MP4 is recommended, decoded on the PC using installed Windows codecs. Configure Fit, Loop, Speed and FPS; Pause video freezes the current frame and Restart video begins again. Existing video-placeholder themes attempt playback. Info Screen imports embed the video in `.t3theme`; Hybrid overlays save links to the original file in `.pchybrid`, so keep linked files available.

3.5-inch serial output uses RGB565 frames, with 3 fps Auto and a 5 fps maximum. 5.2-inch WinUSB output uses JPEG frames, with 12 fps Auto and a 20 fps maximum. Completed USB transfer times can reduce these limits further. These are conservative application limits, not measured physical smoothness guarantees. Native 5.2-inch H.264, desktop mode and SD-card playback remain outside this backend.

This first version limits sources to Full HD (including portrait equivalent), imports to 512 MiB and active videos to two. Each worker retains one bounded current frame. Imports copy asynchronously, stale output frames are replaced and inactive video resources are released. Unsupported media shows an inline status. Audio is deselected and never played. Other formats depend on installed Windows codecs; Windows N may need Microsoft's Media Feature Pack. No codec binaries or FFmpeg are bundled.

## Export diagnostics

Settings > Troubleshooting > Export diagnostics saves a JSON file at a location you choose. Reports contain app/Windows versions, selected transport/protocol, resource counters and recent exception types/error codes. Photos, theme content, account names, personal paths and raw error messages are excluded. Nothing is uploaded automatically.

## Install and validation

Exit the previous version from its tray menu, extract the full portable ZIP into a new folder and run PCInfoScreenStudio.exe. Existing themes remain readable; new video playback settings need alpha.14.

Release requires Windows build/controller/WPF checks plus published EXE and extracted ZIP smoke tests. Video checks use an original generated H.264/AAC clip for actual pixels, vertical orientation, pause/unpause, loop, EOF, speed, decoder limits, cleanup and unsupported media. Diagnostic export checks JSON structure and exclusion of private exception messages. Physical video rates, long-duration memory and real reconnect tests remain pending on both display families.
