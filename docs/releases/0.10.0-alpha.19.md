# PC Info Screen Studio 0.10.0-alpha.19, portable alpha

Adds **Brightness** beside **Start/Stop display** in the top toolbar. Click it to open a compact 0 to 100% slider and a **Reset to 50%** button. The current percentage stays visible in the toolbar. Keyboard arrow keys adjust the slider; Escape closes it. Changes work in every app mode and on the Hardware page.

The 3.5-inch serial and 5.2-inch USB families remember separate brightness levels in app settings. Existing installations default to the previous 50% level. Disconnected changes are saved for the next connection; restart/reconnect applies the chosen level in the initial setup. Brightness is not part of a theme, so opening a theme does not override it. Zero brightness dims the physical display without stopping playback or changing the app preview.

Live updates are debounced and coalesced, including edits while a command is in flight. Commands use the existing router/backend I/O gates to avoid mixing brightness bytes with image payloads. Serial uses the existing inverted 0..255 mapping; the 1CBE:0050 USB family uses brightness command 14 with the exact-family Python reference's 0..102 mapping. Explicit brightness changes send no sync/reset handshake. Mode changes still send no brightness command. Colour tests retain the chosen serial brightness instead of resetting it to 50%.

If a device rejects a brightness request, the app reports that the saved level will be retried on reconnect and retains the image session. Actual dimming range, perceptual response and firmware behavior need physical confirmation on the owner's two screens; software checks do not prove those properties.

Validation covers defaults/clamping, separate persisted family levels, disconnected presets, reconnect initialization, rapid/in-flight coalescing, backend routing, USB packet values and JPEG continuity. The previous simulated firmware that rejects mid-session setup also checks that a rejected explicit brightness request does not disconnect image output. Actual WPF checks exercise popup opening, delayed edits/final commit, labels, Reset, Escape, family changes, theme independence and the minimum window width. Full Windows build/controller/WPF and published EXE/extracted ZIP checks gate release.

Exit the previous version from its tray menu, extract the full ZIP into a new folder and run PCInfoScreenStudio.exe.
