# PC Info Screen Studio 0.9.1 alpha 1

- Keyboard nudging follows the configured grid spacing when Snap is enabled.
- Text, Value, and Circular Gauge font sizes remain fixed while widget bounds are resized.
- Data source selectors display their current selection.
- Editor panels open by default and remember their state.
- Button hover states and tooltips retain readable contrast.
- The canvas supports Ctrl/Shift selection, drag-box selection, grouping, group movement, multi-object alignment, and smart alignment guides.
