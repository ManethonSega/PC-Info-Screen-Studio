# PC Info Screen Studio 0.10.0-alpha.5, portable alpha

Search now configures the selected widget, following the same left-to-right workflow as the editor.

## Changed

- Add a widget using the existing buttons on the left, then select its data source on the right.
- **SEARCH** filters the **Source** dropdown. `GPU` shows all standard GPU sources; `CPU temperature` finds `CPU.Temperature`. Enabled advanced sensor entries are included.
- Searching never adds widgets and never changes the current sensor. Choose a source to update only the selected widget.
- **Clear** restores the full source list. Empty results and switching widgets preserve and display each widget's actual source.
- Info Screen and Hybrid use the same configuration workflow. Source choices remain saved in their themes.
- README instructions and interface screenshots match the new workflow.

## Download

Extract the entire **PCInfoScreenStudio-0.10.0-alpha.5-win-x64.zip** folder, then run `PCInfoScreenStudio.exe`. The package is self-contained and includes `START-HERE.txt`, device compatibility notes, licences and exact source/build metadata. `SHA256SUMS.txt` verifies the ZIP. The source archives at this tag match its `build-info.json` revision.

## Validation and limits

Windows checks exercise the actual search box and Source dropdown, GPU and multiword filtering, choosing a sensor, empty results, clearing, dynamic advanced sensors, switching widgets, Hybrid editing and saving/reopening its selected source. Existing mode, session, tray and reconnect checks run as well. The published application and extracted portable ZIP start in smoke-test mode.

This remains an **unsigned alpha**, focused on 480 × 320 Revision-A USB serial screens. Physical-screen testing, a real Windows restart and new-user testing remain pending. Video import is a placeholder; full video playback is unavailable. Photos and some Hybrid assets remain linked to their local PC paths. See the included `VALIDATION.md` and `DEVICE-COMPATIBILITY.md`.
