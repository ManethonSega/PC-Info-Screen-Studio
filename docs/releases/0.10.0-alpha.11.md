# PC Info Screen Studio 0.10.0-alpha.11, portable alpha

This release brings the previously local TURZX test builds into the public repository and consolidates obsolete branches while preserving their history.

## Changes

- Experimental TURZX 5.2-inch smart-screen USB output for all three modes.
- Choose 3.5-inch or 5.2-inch in the top bar. Canvas sizing follows the selected display, including imported or blank themes. Both devices can remain connected.
- JPEG output for all TURZX frames. Mode changes reuse the live connection, removing the setup step that caused alpha.10 to disconnect and freeze on the last frame.
- Clearer sensor search results and display updates independent of slow sensor/weather requests.
- Faster GIF composition with compressed GIF data up to 64 MiB per file cached in RAM.
- Large graph/bar headings grow downward without top clipping; resize grips retain selection.
- Independent Photo Frame and Hybrid playlists, settings and resume positions.
- Recovery copies are written again only after another edit.
- Source, compatibility, validation and branch-consolidation documentation updated.

## Download

Extract the whole `PCInfoScreenStudio-0.10.0-alpha.11-win-x64.zip` into a new folder. Completely exit the previous app from its tray icon, then run `PCInfoScreenStudio.exe`. The ZIP is self-contained, includes the verified optional PawnIO sensor installer, licences, getting-started instructions and exact source/build metadata. Verify the ZIP with `SHA256SUMS.txt`.

For the 5.2-inch screen, close vendor software and select 5.2-inch in the top bar. The existing smart-screen WinUSB driver must be accessible. Desktop Mode, SD-card playback and H.264 video are not implemented.

## Validation and limits

Publication follows the complete Windows build and WPF/controller workflow, published-EXE startup and extracted-ZIP smoke checks. Simulated USB checks cover command encryption, JPEG payloads, rotations, failures, newest-frame delivery and keeping Stop display active across mode changes. GIF composition, large-font rendering, independent playlists, canvas/device selection and edit-only recovery writes are checked too.

The owner confirmed initial output in all three modes and later confirmed the large-font and playlist fixes. The alpha.11 mode-switch correction still requires a physical retest. Automated checks do not establish sustained hardware reliability, GIF speed, disk usage or real reboot/sleep behaviour. Exact USB IDs and driver details remain to be recorded.

This is an unsigned experimental alpha, not a beta. Photos remain linked to PC paths. GPL-3.0-or-later; third-party licences remain included.
