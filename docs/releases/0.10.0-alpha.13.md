# PC Info Screen Studio 0.10.0-alpha.13, portable alpha

Hardware names can now be added as editable widgets, and rendered text supports colour emoji.

## Hardware-name widgets

Choose **Hardware name** under Add in Info Screen or Hybrid overlays. Select CPU, GPU, SSD/drive names or RAM brand/model. The default follows the current PC's detected hardware. Editing **Displayed name** switches to a persistent custom name, which sensor refreshes do not overwrite. Tick **Use detected name** to return to automatic. Overrides survive duplication, themes and session snapshots.

Windows hardware inventory runs once in the background, independently of low-level sensor access. Multiple distinct drive/module names are joined with a separator. RAM manufacturer/model information can be missing or generic in firmware; the app excludes placeholders and does not invent a brand.

## Colour emoji

Widget text, hardware names, sensor labels/values and photo captions now use Segoe UI Emoji fallback while preserving the selected font for ordinary text. Whole Unicode graphemes are shaped, including supported skin tones, variation selectors, keycaps and joined sequences. Emoji retain their palette rather than taking the widget text colour. Ordinary caption text retains its outline; colour emoji are not drawn again in the outline pass.

Use **Win + .** or paste emoji such as 👌💕👏 into text fields. Native WPF editing fields can show monochrome glyphs, while the rendered canvas and physical screen output are coloured. Available emoji depend on the Windows system font; unsupported newer Unicode sequences may lack a matching glyph. No Microsoft font is bundled.

Mixed-text layouts are cached with a 128-entry limit; long pasted strings are not retained. Pure text keeps the existing render path. USB connection/transfer, GIF playback and independent playlists are unchanged.

## Download and checks

Extract the full `PCInfoScreenStudio-0.10.0-alpha.13-win-x64.zip` into a new folder after exiting the previous app from its tray icon. Run `PCInfoScreenStudio.exe`. Existing themes remain readable; themes containing the new Hardware name widget require this version or newer.

Publication requires the complete Windows WPF/controller suite and executable/ZIP startup checks. Additional checks cover firmware name formatting, actual property-field editing, refresh-safe overrides, duplication, Info Screen/Hybrid persistence, coloured output pixels with a custom font, joined emoji widths and photo captions. A rendered sample is captured for visual review. These checks do not establish physical USB colour quality or hardware-name accuracy on every PC.
