# Alpha.32: independent Matrix fonts and alignment per tile

Every Matrix tile now keeps its own four-, five- and ten-dot font preferences.
Click a column or tile and change its font; neighboring tiles retain their
own fonts. Switching row heights, layouts, content types or restarting the app
preserves each tile's choices, including currently inactive tiles.

Older saved layouts inherit their previous shared fonts on each tile. Explicit
new per-tile choices take precedence, including default fonts such as Tom Thumb.
Invalid font fields recover independently without losing other valid tile data.

Each tile also saves Left, Centre or Right alignment for text, sensor values
and UTC clock content. Long messages that need scrolling continue to use the
full tile width. Pixel art keeps its authored grid positions.

All fourteen fonts and the 4+4, 5+5, 4+5 and 5+4 row arrangements remain included.
The same tile-specific bitmap choice drives the preview and USB output. The
font controls are labelled as affecting this tile.

Development candidate on draft PR #33, separate from the published alpha.20.
Physical Matrix qualification and the documented font release review remain open.
