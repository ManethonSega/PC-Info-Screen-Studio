# 0.10.0-alpha.7

Adds experimental TURZX 5.2-inch direct smart-screen output to Info Screen,
Photo Frame and Hybrid, alongside the existing 3.5-inch serial display backend.

- Detects USB 1CBE:0050 separately from COM ports, using Windows WinUSB.
- Offers a 1280 × 720 canvas and retains that resolution across orientation
  changes, saved themes and sessions.
- Sends lossless PNG frames with a bounded JPEG fallback for complex photos.
- Reuses continuous reconnect and latest-frame-only output.
- Adds USB protocol and high-resolution persistence checks.
- Includes the recent startup delay, device identity recovery, continuous
  retry and best-effort exit clearing improvements.

Close TURZX software, return the screen to smart-screen mode and select
**Settings → Theme canvas size → 5.2-inch · 1280 × 720**. Press **Detect screen**,
select the TURZX USB device, then **Start display**. Keep protocol on Auto.

This is an unsigned, portable, self-contained Windows x64 alpha. Full Windows
build, controller/UI and extracted-package startup checks run before release.

**Physical 5.2-inch validation remains pending.** Confirm your device's USB
identity and run the colour test. Windows Desktop Mode, SD-card management and
H.264 playback are separate features and are not added by this release. The
app does not replace or install USB drivers. See docs/TURZX-52.md.
