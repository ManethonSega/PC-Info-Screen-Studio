# PC Info Screen Studio 0.10.0-alpha.26, separate panel surfaces and photo scrolling

Each open panel now paints its own framed surface. The area below it uses the workspace background, and its width divider ends with the stack. Both sides share this behavior in every mode. The navigation rails remain available.

Photo Frame and Hybrid now use a single internal scrolling area in + Photos: the playlist. Import, playback, position and folder controls stay outside it. Long photo names use ellipsis with full-name tooltips, and horizontal scrolling is disabled. Playlist height remains bounded, preserving virtualization.

Pinned controls retain enough room when other panels open, folders expand, or an older explicit height is too small. The whole dock remains scrollable when all open panels cannot fit the window.

Windows verification and native capture review for the latest revision are recorded in [draft PR #32](https://github.com/ManethonSega/PC-Info-Screen-Studio/pull/32). This is a development build, not a published release.
