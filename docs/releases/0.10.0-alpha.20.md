# PC Info Screen Studio 0.10.0-alpha.20, portable alpha

Adds validated backups and automatic recovery for settings and the private last-session snapshot. A damaged or missing primary can recover from its last good backup, with a dismissible inline notice. Unreadable files are retained for diagnosis. Backups may be older than the latest work; failed writes preserve valid existing data. Session recovery keeps unsaved edits, independent mode settings, photo references and embedded assets.

File operations now disable conflicting New/Open/Save/import/library actions, Undo/Redo and mode/model changes. The footer shows progress and Cancel. Images/GIFs/videos/fonts and photo metadata/folders are prepared asynchronously. Editing during Info Screen Save stays available, and edits made after its snapshot remain unsaved. Workspace files stay alive until background readers finish. Failed/cancelled loads and copies retain the previous workspace or saved destination. Mode settings saves now replace files through unique pending files.

Images, prepared photos and GIF resources share a 128 MiB retained cache budget. Unused decoded resources are evicted while original workspace files remain available for Undo. GIFs retain a composited frame/decoder, use up to 16 MiB of compressed RAM data per source and preserve their active timeline when a decoder is recreated. Current/transition photos and one prefetched next photo stay warm. Resources being drawn are protected from Clear/eviction. Diagnostics adds path-free cache counters.

The cache budget is not a whole-process RAM cap: temporary draws, native decoder buffers, fonts/text, video, frame queues and runtime overhead are separate. Very large images/GIFs must fit a 64 MiB single decode bitmap; use screen-sized media for lower decode cost. Large sessions need extra local space for one backup and additional validation I/O. Details and limits: docs/STABILITY.md.

Regression checks cover corrupt/missing primary recovery, valid backup preservation, failed/cancelled writes, older settings, concurrent saves, media lifetimes, actual WPF guards/notices/progress, GIF composition/lifetimes and 500 rendered mode frames with 30 photos/two GIFs under an 8 MiB test budget. Full Windows/controller/WPF and published EXE/extracted ZIP checks gate release. Extended representative hardware resource measurements remain separate.

Exit the previous version from its tray menu, extract the full ZIP into a new folder and run PCInfoScreenStudio.exe. Existing app data and reusable theme formats are retained. Backups are managed automatically; no setup confirmation is added.
