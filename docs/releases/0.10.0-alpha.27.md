# PC Info Screen Studio 0.10.0-alpha.27, draggable and floating panels

Drag a panel header or its rail entry. Drop over a left/right docking target to stack it there, or outside the docks to open a floating tool window. The cyan preview indicates the insertion point. Escape cancels the drag. The panel’s ⋯ menu provides Float panel, Dock left and Dock right without dragging.

Floating windows use native move/resize behavior and remember their position and size. Their content remains alive when collapsed, moved or hidden. Closing a floating window collapses it; click its rail entry to reopen it. Live view, Hardware, irrelevant modes, minimizing and the tray hide applicable tools. Restoring the editor restores them. Saved positions on removed monitors recover to a current working area.

Reset workspace closes floating windows, restores original panel sides and automatic sizes, and enables Fit. Workspace changes remain separate from themes and Undo. Docked panels reserve canvas space; floating windows can overlap it by choice.

Windows checks and captures are tracked in [draft PR #32](https://github.com/ManethonSega/PC-Info-Screen-Studio/pull/32). Mixed-DPI multi-monitor moves, Narrator and high contrast still require interactive qualification. This candidate does not publish a GitHub release.
