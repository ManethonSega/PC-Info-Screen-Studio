# PC Info Screen Studio 0.10.0-alpha.12, portable alpha

The editor now uses a coordinated navy, slate and cyan visual system inspired by MechKeyMesh. Its three-column structure, commands and screen workflows remain in place.

## Changes

- Shared palette: Mesh Cyan `#21E6E8`, Neon Aqua `#18D7F1`, Electric Blue `#1C8DFF`, Deep Navy `#081327`, Carbon Slate `#1A2436`, Silver White `#EDF2F7` and alert Orange `#FF922E`.
- Calm layered surfaces, consistent rounded controls, restrained borders and smaller section labels.
- Cyan primary actions with dark readable text. Neutral secondary actions and cyan selections, with blue keyboard focus and orange numeric validation.
- Coordinated Settings, hardware cards, menus (including the tray), tooltips, sliders and canvas selection handles.
- Consistent input spacing and more space between property sections, preserving all existing bindings, handlers and controls.
- The owner reports alpha.11 working correctly on their physical setup, including mode switching. USB transfer, photo playback, theme persistence and rendering logic are unchanged here.

## Download

Extract the whole `PCInfoScreenStudio-0.10.0-alpha.12-win-x64.zip` into a new folder. Completely exit the previous app from its tray icon, then run `PCInfoScreenStudio.exe`. Themes and user settings continue using the existing storage and formats. The portable ZIP includes the verified optional PawnIO prerequisite, licences and exact build metadata. Check `SHA256SUMS.txt` if verifying the download.

## Validation

The release requires the full Windows build, controller/WPF checks, real WPF UI captures, published-EXE smoke test and extracted-ZIP smoke test. Readability checks include actual primary-button, helper-label, selected-item and tooltip backgrounds. Slider checks verify the value reaches its template track and the thumb remains present.

The owner's alpha.11 report is evidence for one setup. Broader hardware compatibility and Windows scaling at 125%, 150% and 200% remain separate physical checks. This unsigned alpha is not a beta. TURZX Desktop Mode, SD-card playback and H.264 video remain unsupported.
