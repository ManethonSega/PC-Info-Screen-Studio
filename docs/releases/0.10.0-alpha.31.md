# Alpha.31: Matrix font collection and mixed row heights

Matrix mode now offers the complete selected collection: four four-dot choices,
six five-dot choices and four ten-dot choices. Each height keeps its own saved
selection; click a tile to see the relevant font menu. All fourteen choices are
included for development, without a local font-file loading step. Redistribution
permission for Limitdot H4 and piconano remains a release-review item.

Two-row layouts now offer **4+4**, **5+5**, **4+5** and **5+4**, with two, zero,
one and one empty rows respectively. Text, sensors, clock and pixel art use
the same geometry in the preview and USB output. Hidden artwork survives
layout changes. Existing four-/five-row preferences remain readable.

Ten-dot condensed fonts double height only. Petty uses uppercase characters.
The mem five-dot variant fits its Q inside five rows. Font credits, applicable
licenses and exact adaptations are documented in [the font reference](../research/MATRIX_FONTS.md).

Development candidate on draft PR #33, separate from the published alpha.20.
Physical Matrix qualification remains open.
