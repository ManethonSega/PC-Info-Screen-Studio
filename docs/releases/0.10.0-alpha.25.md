# PC Info Screen Studio 0.10.0-alpha.25, content-sized dock panels

Panels on both sides now open at their content height in every mode, leaving spare space below short panels. Automatic panels grow and shrink when their content changes. Long sections are bounded and scroll; several open panels share the available height limit without stretching short sections.

Mouse and keyboard divider resizing remain available. Only an explicit resize creates a remembered height. Reset workspace restores automatic sizing. Previous panel order, open states and widths remain valid; older relative height weights no longer force full-height panels.

The photo-input panel is now called **Add photos** in Photo Frame and Hybrid, including its rail label, header and canvas guidance. Folder watching and linked playlists remain under **Add photos > Folders & playlists**.

Windows verification and native capture review for the latest revision are recorded in [draft PR #32](https://github.com/ManethonSega/PC-Info-Screen-Studio/pull/32). This is a development build, not a published release.
