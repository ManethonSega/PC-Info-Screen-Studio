# Alpha.36: Matrix heights, labelled bars and animation bank

Every Matrix widget now supports 4-, 5-, 6- and 10-dot heights. Six-dot text
uses the selected five-dot bitmap glyph without distortion and reserves one
blank row above it. Pixel art and animations have native six-row variants.

Progress bars now use one of three explicit widths: 30, 45 or 60 LEDs. An
optional label, including colour emoji, is rendered before the bar inside that
selected width. The existing twelve styles, sensor/manual values, ranges,
colours and alarms remain available.

Rocket moved from the main widget buttons into a dedicated **Animations** bank.
Its sprite now has a changing yellow, orange and red fire trail. The same bank
adds original native-grid versions of crab walk, cat walk, starfield, rainbow,
breathing, wave, two tone, fade, gradient and meteor, following the animation
categories observed in NexLinq without redistributing vendor code or artwork.

Text can animate from either side. Moving text and animation layers save their
direction, speed, play state and a 60-dot side-panel or 90-dot full-panel area.
The renderer clips every frame to the selected area and continues to use the
existing acknowledged, non-queuing Matrix output path.

Automated checks cover every supported height and area, all bar widths, labels,
movement, direction, pause, persistence and actual WPF selectors. Smoothness and
timing on a physical Matrix 900 remain owner qualification items.
