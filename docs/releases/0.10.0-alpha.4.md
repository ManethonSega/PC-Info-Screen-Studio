# PC Info Screen Studio 0.10.0-alpha.4, portable alpha

A focused UI polish release for the existing Info Screen, Photo Frame and Hybrid workflows.

## Download and start

Download **PCInfoScreenStudio-0.10.0-alpha.4-win-x64.zip**, extract the entire folder to a permanent location, then run `PCInfoScreenStudio.exe`. No separate .NET runtime installation is needed. Read `START-HERE.txt` for connection, Windows startup, sensor access and tray operation.

The release includes `SHA256SUMS.txt`. GitHub's source archives at this tag match the commit recorded in the ZIP's `build-info.json`.

## Changed

- Explicit dark templates for dropdowns, selected layers, checkboxes, text inputs and expandable sections; readable hover and keyboard-focus states.
- Consistent control sizes and section headings, secondary toolbar icons, clearer labels and hover explanations, dark scrollbars and a dark tray menu.
- Direct Add buttons remain on the left, sensor search remains on the right, and mode-specific panels, top-bar Settings and Edit/Live switching are preserved.
- Windows startup with one-time task approval, remembered theme/mode/workspace, and automatic reconnection are included. Manual launches may still request UAC approval.
- A self-contained portable download, getting-started guide, device compatibility record and validation record are included.

## Validation

The Windows release workflow builds, runs controller and actual WPF tray-workflow checks, saves/reopens each mode, verifies session restoration and simulated reconnects, captures UI controls, tests the published executable, and extracts/tests the final portable ZIP before publication. The exact workflow and source revision are recorded in `build-info.json`.

These checks do **not** prove physical-device reliability, sustained memory behaviour, a real Windows reboot, or first-time user success. See `VALIDATION.md` for the remaining checks.

## Known limitations

- Device support focuses on 480 × 320 Revision-A USB serial screens. The owner's working setup is documented; broader models are unverified. The 5.2-inch desktop-monitor device is not supported by this serial output path.
- The build is unsigned. There is no installer or automatic updater.
- Video import displays a placeholder; full video playback is not implemented. GIF playback and photos are supported, with physical speed limited by USB/display bandwidth.
- Photo playlists and some Hybrid assets use local paths. Original photos are not embedded in settings themes.
- Sensor availability depends on hardware, driver and permissions. Full administrator sensor access requires an administrator Windows account.
