# PC Info Screen Studio 0.10.0-alpha.24, consistent widget names and photo inputs

Hybrid now calls its add-tools panel **Widgets**, matching Info Screen. Its rail label, header, tooltips and empty-state guidance use the same terminology.

Photo Frame and Hybrid now keep folder watching and saved linked playlists inside **Photos > Folders & playlists**. The separate Sources panel is removed. Slideshow and Captions remain independent panels. Existing photo and Hybrid widget panel arrangements, watched folders and playlists are preserved.

Windows verification and native capture review for the latest revision are recorded in [draft PR #32](https://github.com/ManethonSega/PC-Info-Screen-Studio/pull/32). This is a development build, not a published release.
