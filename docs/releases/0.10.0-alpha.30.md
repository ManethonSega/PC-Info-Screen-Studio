# Alpha.30: selectable five-dot Matrix fonts

Five-dot rows expose a saved font menu: Tom Thumb or PixelFont 5×5 Thin. Native bitmap glyphs feed text, sensors and clock in both preview and USB output. The wider font fits fewer characters. Lowercase descenders are positioned within the five-row band; spacing and scrolling are retained. Four- and ten-dot defaults are unchanged pending font review. Source license notices are bundled. Physical Matrix output remains experimental.
