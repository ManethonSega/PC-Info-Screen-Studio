# PC Info Screen Studio 0.10.0-alpha.6, portable alpha

A focused update to make empty workspaces, alignment and numeric editing easier to understand.

## Changed

- Empty Photo Frame previews show **Add photos or choose a folder**. Hybrid also shows **Add an overlay** until an overlay exists. These editor hints disappear in Live view and are never sent to the physical screen.
- Widget properties hide when no layer is selected, including Hybrid position, typography and colour controls.
- Six illustrated alignment buttons replace the single-letter labels. Hover help explains canvas alignment for one widget and selection-bounds alignment for multiple widgets.
- Invalid dimensions, opacity, sensor ranges and photo settings show an inline explanation. Invalid drafts preserve the last valid setting; corrected values commit when leaving the field. Partial typing remains possible and decimal parsing respects the field culture.
- README workspace screenshots reflect these changes. Existing direct Add buttons and source-search workflow are preserved.

## Download

Extract the entire **PCInfoScreenStudio-0.10.0-alpha.6-win-x64.zip** folder, then run `PCInfoScreenStudio.exe`. The package is self-contained and includes getting-started instructions, licences, device notes and exact source/build metadata. `SHA256SUMS.txt` verifies the ZIP.

## Validation and limits

Actual WPF checks cover prompt visibility, selection/deselection, all six alignment actions, multi-selection alignment, inline errors, correcting drafts, invalid range endpoints, non-finite input, comma decimals, photo settings and Hybrid isolation. Existing source search, theme save/reopen, session, tray and simulated reconnect checks also run. The published executable and extracted portable ZIP pass startup smoke checks before publication.

This remains an unsigned alpha focused on 480 × 320 Revision-A USB serial screens. Physical-screen, real Windows reboot and first-time-user validation remain pending. Video playback is not implemented. Photos remain linked to their PC paths. See the included validation and device-compatibility documents.
